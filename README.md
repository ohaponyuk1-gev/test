# Калькулятор розмитнення легкового автомобіля

Односторінковий калькулятор (`index.html`, без збірки та залежностей) для попередньої оцінки митних платежів при ввезенні легкового автомобіля в Україну.

Відкрийте `index.html` у браузері — файл повністю самодостатній (HTML + CSS + JS в одному файлі), окремий сервер не потрібен.

---

Другий інструмент у цьому репозиторії — **[AP Dealers Hub, фінансова модель](AP-DEALERS-HUB.md)** (`ap-dealers-hub.html`): облік інвесторів, дилерів, авансів, економіки по VIN, каси, PROCAR/VAT, курсових різниць і прогнозу ліквідності для бізнесу закупівлі авто в Кореї під українських дилерів.

## Що вводиться

**Дані автомобіля — з європейського техпаспорта** (реєстраційного документа / Certificate of Conformity), поля позначені кодами гармонізованого сертифіката:
- `A` — VIN
- `B` — дата першої реєстрації → з неї автоматично рахується вік автомобіля
- `D.1` / `D.3` — марка / модель (довідково)
- `P.1` — робочий об'єм двигуна, см³
- `P.3` — тип палива / двигуна (бензин, дизель, газ, гібрид, електро)

**Митна вартість** — сума з інвойсу/договору купівлі-продажу (EUR або USD) плюс витрати на транспортування до кордону України (ст. 58–59 Митного кодексу).

**Курси валют**
- Курс НБУ (USD/UAH, EUR/UAH) — кнопка «Отримати курс НБУ автоматично» звертається напряму до публічного JSON API `bank.gov.ua/NBUStatService`. Цей курс використовується для перерахунку митної вартості й акцизу в гривню, як того вимагає законодавство.
- Курс обмінного пункту [x-change-x.com/rivne](https://x-change-x.com/rivne/) — вводиться вручну (сайт не надає публічного API, і браузери, як правило, блокують крос-доменне зчитування таких сторінок за політикою CORS; кнопка спроби автоматичного зчитування залишена в коді для прозорості, але не гарантує результат). Підсумкова сума митних платежів у гривнях ділиться на цей курс — так калькулятор показує, скільки доларів потрібно за курсом саме цього обмінника.

## Формула розрахунку

```
Митна вартість, грн = (вартість за інвойсом + транспортування) × курс НБУ (валюти інвойсу)
Мито                = Митна вартість × ставка мита (типово 10%, для обох полів — ЄС і не-ЄС)
Віковий коефіцієнт  = ціле число повних років з дати першої реєстрації, не більше 15
Акциз (ДВЗ)         = об'єм двигуна (см³) × базова ставка (EUR/см³) × віковий коефіцієнт × курс НБУ EUR
Акциз (електро)     = ємність батареї (кВт·год) × ставка (EUR/кВт·год) × курс НБУ EUR
ПДВ                 = (Митна вартість + Мито + Акциз) × ставка ПДВ (типово 20%)

Разом до сплати, грн = Мито + Акциз + ПДВ
Сума в USD (x-change-x.com) = Разом до сплати, грн ÷ курс купівлі USD обмінника
```

Базові ставки акцизу за замовчуванням: **0,05 EUR/см³ для бензину** (до 3000 см³) і **0,075 EUR/см³ для дизеля** (до 3500 см³).

## ✅ Звірено з фактичними розрахунками

Формула та базові ставки акцизу (0,05 бензин / 0,075 дизель EUR/см³), ставка мита 10% і використання курсу **купівлі** USD (а не продажу) для фінального ділення — звірені й підтверджені співпадінням до копійки на 6 реальних прикладах розмитнення (DACIA, TOYOTA, PEUGEOT, HYUNDAI, SKODA, RENAULT) з робочої таблиці користувача (стан на 12.08.2026).

**Не підтверджено окремо** (взято за типовою логікою подвоєння ставки, у наданих прикладах таких випадків не було):
- Ставки акцизу для двигунів понад 3000 см³ (бензин) / 3500 см³ (дизель).
- Ставки для газу (LPG/CNG), гібридів і електромобілів.
- Диференціація мита за походженням авто (0% для ЄС за наявності сертифіката EUR.1) — у наданих прикладах завжди застосовувалось 10% незалежно від походження.

## ⚠️ Про ставки

Ставки мита, акцизу, ПДВ та віковий ліміт визначаються Податковим кодексом України (ст. 215) та Митним кодексом і періодично змінюються Верховною Радою. У калькуляторі вони винесені в розділ «Ставки та коефіцієнти» як **редаговані значення за замовчуванням** — перед використанням для реальної сплати звірте непідтверджені пункти вище з чинною редакцією закону на [zakon.rada.gov.ua](https://zakon.rada.gov.ua/laws/show/2755-17) або сайтом [Державної митної служби](https://customs.gov.ua) і за потреби відкоригуйте поля. Калькулятор не є податковою консультацією; остаточну суму визначає митний орган на підставі поданої декларації.
